# Portfólio do 4º semestre

Página estática em HTML, CSS e JavaScript, sem dependências ou etapa de build.

## Prévia local

Abra `index.html` no navegador ou sirva esta pasta com `python -m http.server 8000` e acesse `http://localhost:8000`.

## Conteúdo a completar

- Edite `projectAreas` em `main.js` com descrições de atividades realmente realizadas. Inclua links apenas quando os repositórios ou demonstrações estiverem publicados.
- Adicione registros reais de cursos e certificados no painel `#certificacoes` em `index.html`.
- Os links pessoais no rodapé reaproveitam os endereços já existentes no portfólio do repositório; confirme que continuam corretos.
